# Public Raw PDF Sources

This folder contains source PDFs listed in `../../manifests/irpf_raw_pdf_manifest.csv` with:

- `document_role = source_pdf`
- `access_category = public_url_identified`

The files are tracked with Git LFS. They are included for research reproducibility, but source-specific terms should still be reviewed before redistribution outside this repository.

Current contents:

- 85 source PDFs
- approximately 1.82 GB

Not included here:

- source PDFs received through private correspondence;
- local source PDFs for which no public URL has been identified; these are stored separately in `../local/`.
