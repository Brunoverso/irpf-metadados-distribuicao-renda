# Refined Macro Factors

This folder stores annual conversion factors derived from the raw macro series.

## Files

- `usd_2026_conversion_factors.csv`: one row per year, joining the annual BCB exchange rate with annual-average U.S. CPI. The file reports the nominal domestic-currency-per-USD exchange rate, the annual CPI average, and the CPI multiplier used to express nominal dollars in target-year dollars.

The current target year is 2026. Because 2026 is not complete yet, the CPI target average uses the available months only and is marked as `partial`.
