# Metadata Table Assets

This folder contains generated table assets for the source-metadata module.

## Files

- `irpf_distribution_metadata_reference_table.csv`: compact CSV table generated from `data/trusted/irpf_distribution_source_metadata_yearly.csv`.
- `irpf_distribution_metadata_reference_table.pdf`: PDF rendering of the same compact table, formatted for academic review.

Both files are generated by:

```powershell
python scripts/build_all_assets.py
```
